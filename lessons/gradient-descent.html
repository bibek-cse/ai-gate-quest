Part B · 1 / 15 · Beginner

1. The problem: find the bottom

Training a model means choosing numbers w (weights) that make a loss f(w) as small as possible. The loss measures how wrong the model is.

Toy loss: f(w) = (w − 3)². Its bottom is at w* = 3, where f = 0.

Here we can see the answer. A neural network has millions of weights, and solving "slope = 0" with algebra is impossible. So we walk downhill step by step. That walk is gradient descent.

Part B · 2 / 15 · Beginner

2. Slope tells the way down

f′(w) = limh→0 [f(w+h) − f(w)] / h

The derivative is the slope of the curve at w.

  • f′(w) > 0: going right goes up, so step left.
  • f′(w) < 0: going right goes down, so step right.
  • |f′(w)| large: steep. Near 0: almost flat, close to a min (or max).

For our loss: f′(w) = 2(w − 3). At w = 0: f′ = −6, negative, so move right, towards 3. ✓

Rule of thumb: always step against the sign of the slope.

Part B · 3 / 15 · Beginner+

3. Many weights: the gradient

∇f(w) = ( ∂f/∂w1, ∂f/∂w2, …, ∂f/∂wn )

Example: f(x,y) = x² + 3y² gives ∇f = (2x, 6y). At (1,1): ∇f = (2, 6).

Why steepest? The slope in a unit direction u is Duf = ∇f · u = ‖∇f‖ cos θ. It is largest when θ = 0 (u along ∇f) and most negative when θ = 180°. So −∇f is the steepest way down, and ∇f is ⟂ to the contour lines.

Part B · 4 / 15 · Intermediate

4. Why the update rule works

First-order Taylor expansion around w, for a small step Δ:

f(w + Δ) ≈ f(w) + ∇f(w)ᵀ Δ

Choose Δ = −η ∇f(w), η > 0:

f(w − η∇f) ≈ f(w) − η ‖∇f(w)‖² ≤ f(w)

The loss goes down, as long as η is small. Taylor only holds near w, so a huge step can overshoot.

wk+1 = wk − η ∇f(wk)

η = "learning rate" = step size.

Part B · 6 / 15 · GATE trick

6. Track the error, not w

Let ek = wk − 3 (distance from the minimum). Then

ek+1 = ek − η·2ek = (1 − 2η) ek

ek = (1 − 2η)k e0

With η = 0.25, e0 = −3: wk = 3 − 3(0.5)k. Check k = 2: 3 − 0.75 = 2.25 ✓. That's an answer in one line, no table.

General 1-D quadratic

For f(w) = (a/2)(w − w*)² (so f″ = a):

ek+1 = (1 − ηa) ek

Everything about convergence lives in the factor r = 1 − ηa.

Part B · 7 / 15 · Intermediate

7. Learning-rate regimes

f(w) = (w − 3)², a = 2, r = 1 − 2η, start w0 = 0:

converges ⇔ |1 − ηa| < 1 ⇔ 0 < η < 2/a

Here 2/a = 1, so warm-up Q3 is (B). With 0 < η ≤ 1/a there is no zig-zag, and η = 1/a lands in one step.

Part B · 8 / 15 · Intermediate+

8. Curvature decides the step

a = f″(w) is the curvature. A sharp, narrow valley (big a) needs a small η. A wide, flat valley allows a big one.

The perfect step for a quadratic is η = 1/a:

w ← w − f′(w) / f″(w)

This is Newton's method. It uses slope and curvature, and solves any quadratic in one step.

In n dimensions, Newton needs the n×n Hessian ∇²f and its inverse, which costs O(n³). With millions of weights that is impossible. Gradient descent needs only ∇f, at O(n) per step. That trade-off is why deep learning uses first-order methods.

Part B · 9 / 15 · Advanced

9. Many dimensions: condition number

Quadratic bowl f(w) = ½ wᵀAw, A symmetric positive definite, eigenvalues λmin … λmax. Along each eigenvector the error obeys page 6:

ei ← (1 − ηλi) ei
  • Stable only if η < 2/λmax (the steepest direction).
  • The slowest direction shrinks by 1 − ηλmin.
  • Condition number κ = λmax/λmin. Best fixed η = 2/(λmax+λmin) gives rate (κ−1)/(κ+1).

Shown: κ = 10. With κ = 100 the rate is 99/101 ≈ 0.98, which is painfully slow. Feature scaling (normalising inputs) lowers κ.

Part B · 10 / 15 · Advanced

10. Convex vs non-convex

Convex: the chord lies above the curve:

f(θx + (1−θ)y) ≤ θf(x) + (1−θ)f(y)

Equivalently f″ ≥ 0 (Hessian positive semidefinite). Then every local minimum is global, and GD with a suitable η reaches it.

Non-convex (neural nets) has local minima, plateaus and saddle points. A saddle point has ∇f = 0 but isn't a minimum: f(x,y) = x² − y² at (0,0) curves up in x and down in y.

Part B · 11 / 15 · Advanced (MIT level)

11. How fast? Convergence rates

L-smooth: the gradient is L-Lipschitz, so curvature ≤ L. μ-strongly convex: curvature ≥ μ > 0.

assumption (η = 1/L)guarantee
convex + L-smoothf(wk) − f* ≤ L‖w0−w*‖² / (2k)
+ μ-strongly convex‖wk−w*‖² ≤ (1 − μ/L)k ‖w0−w*‖²

The first is sublinear, O(1/k). The second is linear (geometric), and L/μ is exactly the condition number κ from page 9.

When to stop

Stop when ‖∇f(wk)‖ < ε, or the loss stops changing, or after a maximum number of iterations. In ML, also stop when the validation loss starts rising (early stopping).

Part B · 12 / 15 · Advanced

12. Batch, stochastic, mini-batch

An ML loss is an average over N examples: f(w) = (1/N) Σi ℓi(w)

gradient usedcost / step
Batch GDall N examplesN
SGD1 random example1
Mini-batchB examples (32–512)B

SGD's gradient is unbiased: E[∇ℓi(w)] = ∇f(w). It's noisy but cheap, and the noise helps escape saddles. To converge, the step size must decay:

Σ ηk = ∞, Σ ηk² < ∞ (e.g. ηk = η0/k)

Robbins–Monro conditions. Mini-batch is the default on GPUs.

Part B · 13 / 15 · Advanced

13. Momentum & Adam

Momentum (heavy ball)

v ← βv + ∇f(w), w ← w − ηv (β ≈ 0.9)

It averages past gradients, so the zig-zag across a ravine cancels while motion along it builds up. That fixes the κ problem from page 9.

Adam: a step size per weight

m ← β1m + (1−β1)g, s ← β2s + (1−β2)g²

m̂ = m/(1−β1t), ŝ = s/(1−β2t)

w ← w − η m̂ / (√ŝ + ε)

Defaults: β1 = 0.9, β2 = 0.999, ε = 10⁻⁸. Weights with big gradients get smaller steps.

Part B · 14 / 15 · Exam craft

14. GATE traps (read twice)

  1. Sign. It's minus the gradient. "+η∇f" is gradient ascent.
  2. Where to evaluate. Use ∇f at the current wk, not the new point.
  3. Stability range. 0 < η < 2/a (or 2/λmax), with strict inequalities. 1/a is the no-zig-zag limit, not the stability limit.
  4. Counting. "After 2 steps" means w2. w0 is the start.
  5. Useful gradients. ∇‖w‖² = 2w, ∇(aᵀw) = a, ∇(½wᵀAw) = Aw (A symmetric), ∇½‖Xw − y‖² = Xᵀ(Xw − y).
  6. Constant factors. ½ in front of a square cancels the 2. Check which form the question uses.

Part B · 15 / 15 · Revision

15. One-page cheat sheet

wk+1 = wk − η ∇f(wk)
  • −∇f = steepest descent, and ∇f ⟂ contours
  • Quadratic: ek = (1 − ηa)k e0
  • Converges iff 0 < η < 2/a, i.e. 2/λmax in n-D
  • η = 1/a: one step (Newton) · 1/a < η < 2/a: zig-zag
  • κ = λmax/λmin: big κ means slow zig-zag; fix with scaling or momentum
  • Convex: local = global · non-convex: saddles, local minima
  • Rates: O(1/k) convex · (1−μ/L)k strongly convex
  • SGD: unbiased but noisy; decay η (Σ η = ∞, Σ η² < ∞)
  • Momentum damps zig-zag · Adam: per-weight steps
